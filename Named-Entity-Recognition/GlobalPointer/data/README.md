# Dataset CLUENER

**CLUENER** — pengenalan entitas bergranularitas halus (bahasa Mandarin).

## 10 label

| Label | Makna |
|-------|--------|
| address | Alamat |
| book | Judul buku |
| company | Perusahaan |
| game | Game |
| government | Instansi pemerintah |
| movie | Film |
| name | Nama orang |
| organization | Organisasi |
| position | Jabatan |
| scene | Tempat wisata |

Detail dan baseline: [CLUEbenchmark/CLUENER](https://github.com/CLUEbenchmark/CLUENER) · leaderboard: [CLUE](https://www.cluebenchmarks.com).

Format file JSON di folder ini digunakan oleh `run_train.py` dan `inference.py`.
